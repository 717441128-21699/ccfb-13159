# 变电站红外/可见光配准融合巡检工具

把巡检机器人双镜头(红外热图 + 可见光图)合成一张图:在可见光的设备细节
上叠加红外温度伪彩,点任意位置读原始温度,发热点自动框选并标注设备部位。

纯前端实现:**配准与融合全部在 WebGL2(GPU)中计算**,其余为 TypeScript,无框架、无构建依赖。

## 运行

```bash
npx tsc            # 编译 src/*.ts -> dist/
node server.mjs    # 打开 http://localhost:8123
```

点「生成全部样例」即自动合成 5 组变电站场景并完成配准+融合+热点检测全流程。

## 功能

- **批次导入**:多选图片文件,按文件名(ir/vis 关键字)自动配对,灰度红外图按温标线性还原温度;「处理全部」逐对自动配准融合
- **样例生成**:隔离开关触头发热 / 绝缘子串球头发热 / 主变套管端子发热 / 母线线夹螺栓发热 / 电流互感器正常工况,带已知的相机偏差(平移/旋转/缩放)、径向畸变(k1)和深度视差真值
- **配准调整**:自动配准 + 手动微调(平移/缩放/旋转/畸变 k1/视差场强度),边缘配准视图(绿=可见光边缘,品红=红外边缘)和视差场矢量显示
- **融合显示**:融合 / 可见光 / 红外伪彩 / 边缘配准四视图;铁红/彩虹/灰度调色板;显色温度区间与叠加强度可调
- **温度读取**:点击融合图任意位置显示该点原始温度(°C)及所在设备
- **发热点清单**:温度越限(环境+14K)连通域自动检测,按温升分级(一般/严重/危急),框选到可见光坐标并标注设备/部位,点击行定位
- **质量指标**:实时显示细节保持率(目标 ≥90%)、低温背景对比度保持率(损失 ≤20%)、配准+融合耗时(限 500ms)

## 技术方案

### 配准(WebGL2)

1. **边缘提取**:Sobel 分方向梯度(R=水平边缘,G=垂直边缘,B=亮度),
   压缩非线性抑制热点强边主导;温度通道用 p2/p98 鲁棒归一化 + 2px 核抑制 NETD 噪声
2. **全局仿射**:在 GPU 上对每个候选(平移/缩放/旋转)计算
   **结构加权互信息(MI)+ 分方向边缘 Dice** 评分,多切片粗搜 → Top-3 候选 →
   两轮坐标下降精化;候选评分带**出厂标定先验的二次罚项**抑制虚假最优
3. **局部视差场**:24×18 网格节点上做窗口 NCC 块匹配(两轮,粗+细),
   处理远近设备视差;3×3 平滑 + NCC 置信度门控(无纹理区衰减到 0)
4. **畸变校正**:径向 k1 模型,着色器内不动点迭代求逆

### 融合(WebGL2)

- 可见光像素 → 视差场 → 仿射逆变换 → 畸变校正 → 红外温度采样(R16F 纹理,半浮点双线性)
- 伪彩按温度门限自适应透明:`alpha = smoothstep(T0, T1, temp) × 强度`,
  调色板颜色用可见光亮度调制(`pal × (0.3 + 1.05×lum)`),
  高温醒目、低温背景完全透明不遮纹理
- 温度纹理与配准边缘纹理分离(全量程 vs 鲁棒归一化),互不影响

### 性能

800×600 可见光 + 320×240 红外,单对配准+融合在软件渲染(SwiftShader)下
约 150–270ms,真实 GPU 上远低于 500ms 限值。

## 目录结构

```
index.html / styles.css   页面与样式
src/
  main.ts                 UI 装配、批处理流水线、交互
  types.ts                共享类型
  gl/engine.ts            WebGL2 引擎(纹理/FBO/渲染调度)
  gl/shaders.ts           全部 GLSL(边缘/评分/视差场/融合)
  gl/half.ts              float32→float16 转换
  registration.ts         配准编排 + CPU 侧坐标变换(与着色器一致)
  hotspots.ts             发热点连通域检测与设备匹配
  metrics.ts              细节保持率/背景对比度指标
  samples.ts              5 种变电站场景合成(含温度场与相机真值)
e2e/test.mjs              端到端验证(puppeteer-core + Edge headless)
```

## 端到端验证

```bash
cd e2e && npm install && node test.mjs
```

生成全部样例并批处理,输出每对的耗时/指标/配准精度(对照真值映射 RMS 误差)
及截图(`shot-*.png` 融合视图,`edge-*.png` 边缘配准视图)。
